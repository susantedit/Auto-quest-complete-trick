# Discord Auto Quest Complete Guide

### Step 1: Download and Install Discord
Get the official desktop application for Windows: https://discord.com/download. Sign in with your Discord account. The browser version cannot spoof desktop game detection.

### Step 2: Enable Developer Tools
1. Press `Win + R` on Windows.
2. Enter `%appdata%/discord/` and press Enter.
3. Locate `settings.json`.
4. Download `setting.json` from this repository and replace `settings.json` in that folder (or paste the code from `setting.json` into it).

### Step 3: Restart Discord
Close Discord completely using Task Manager (`Ctrl + Shift + Esc`) to terminate background tasks, or reboot your PC. Reopen Discord.

### Step 4: Accept Quests
Open Discord, head into User Settings > Quests, and click "Accept Quest" for all available quests you want to finish.

### Step 5: Open Console and Allow Pasting
1. Press `Ctrl + Shift + I` inside Discord.
2. Click the **Console** tab.
3. Type `allow pasting` and press Enter to clear the input warning.

### Step 6: Paste and Execute Script
Copy the full content of `dc script.txt`, paste it into the console, and press Enter. The script will progress through each quest automatically until completion.
